怎么拿链接？（点开看教程）
  1. 在抖音 / 快手 / B站 / 小红书 App 里，点视频右下角 分享；
  2. 选 复制链接；
  3. 回到本页点 快捷粘贴 按钮，会自动粘贴并开始解析。

批量搬运：切换到「主页批量搬运」，粘贴快手账号主页链接（形如 kuaishou.com/profile/xxx），抓取后可勾选下载或存入你的壁纸库。

📑 书签工具（抖音/快手/小红书 100% 可用，零安装）

2026 年起抖音/快手/小红书把视频数据锁进了登录态，网站后台抓不到。书签工具让解析引擎跑在平台自己的页面里（用你的登录态），点一下直接出无水印直链。

📑 把我拖到书签栏

用法：① 把左边按钮拖到浏览器书签栏；② 在抖音/快手/小红书里点分享 → 在浏览器打开；③ 图集先滑动浏览一遍（让图片都加载出来），再点书签栏里的「壁纸解析」→ 自动跳回本站出结果，可直接下载/存库。

解析总失败怎么办

平台对陌生访问有风控，短时间反复重试反而更容易被拉黑——本站已内置防拉黑：同平台自动节流、连续失败 3 次自动冷却 10 分钟。冷却期间请换条链接先玩，或过几分钟再试。

短链打不开/跳登录页 = 链接已失效，重新从 App 里分享一条新的即可。

解析由本仓库自带的「自研解析引擎」完成：不依赖第三方解析接口、不需要本地软件。浏览器端引擎先自己抓页面自己解析（秒级）；没抓到再自动派给 GitHub Actions 代抓，结果写回仓库缓存永久保留。壁纸只作个人收藏用途，作品版权归原作者所有。
